# Handoff replay: Which nonlocal partners are cheap?

At the decision after local isolation, test how many replacement-sum intervals a pairing can choose instead of pricing it only by the number of changed starts. The partner hit can locate a retained block once its replacement interval is known, but the removed block still has to complete the source hit. A useful difference would be a power-saving price against the actual core for an existential class changing order $L$ starts. Losing source dependence in the accounting would be worse than leaving the comparison open.

Both prices use the same two-block moment inequality, and both concern a fixed fraction of the core, not detection-scale deletion. Skip this branch if the proposal reads the whole hidden block, has no sizable retained group, or estimates the signed count without a transport.
