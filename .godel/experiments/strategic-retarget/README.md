# Strategic retarget replay

## Protocol fixed before dispatch

Question: Do two additions to existing decision prompts improve the selection of a neglected test or the response to new evidence? No driver is launched or changed. This is a paired decision replay, not a rerun of the proof or a test of live loop productivity.

| Retarget | `e9bd2b592f272c419fa607a309808636e8172220` against its parent | No change, branch handoff only, or shared frontier change. |
| Control | `ed8887477231d50f6dad67d54ac666af5bdbd02c` against its parent | Same disposition. A prerequisite can advance its own handoff without changing overall strategy. |

Each arm gets a fresh, read-only context at its pin. Use the Companion selector or Main improvement instructions at that pin, subject to the replay restrictions: Only contemporaneous evidence, no run-history search, no edits, no access to other arms, and no campaign adoption. For the two Main cases, the new accepted patch takes the place of a live improvement run record. Both arms can request independent review if needed, by stating what to challenge; the coordinator returns the review before their final disposition. Record that cost.

The discovery addition is: “Which mapped but unpursued test would change a live proof decision? Compare it with continuing your current chain; select on the merits.” The improvement addition is: “Does the landing invalidate an advertised target, remove a premise, or make a blocked test runnable? If that would change the next decision and the handoff does not reflect it, obtain an independent adversarial review of the exact patch against prior evidence before deciding the smallest retarget.”

A separate reviewer sees masked outputs, the pinned evidence, and the rubric, not arm identities, prompt changes, later results, or the actual retarget. Judge discovery by tractability, nonduplication, and the decisions affected by opposite outcomes, not by field or branch. Judge dispositions by valid inference, actionability, and smallest justified scope; penalize a strategic redirect on the control without evidence. Record ties. Install nothing for parity. Recommend a prospective trial only for a material improvement that survives its control; a replay cannot establish live benefit.

**Decision:** Keep Main's current prompt. This replay did not justify an additional mandatory review trigger or a separate program. Advance only the Companion question to a prospective **shadow** trial: On the next fresh handoff, compare it with the existing selector before the outcome is known, without changing or directing the live worker. Score whether it identifies a tractable decision that the existing brief misses, not whether it switches branches. No live prompt was installed. One selection win on a handoff already naming the deferred alternative does not establish improved discovery or proof productivity.
