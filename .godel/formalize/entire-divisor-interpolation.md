For a nonzero entire \(g\) and \(D=\operatorname{div}(g)\), the ideal sheaf
is locally generated at a zero \(a\) by \((z-a)^m\), where
\(m=\operatorname{ord}_a(g)\). The quotient sheaf is zero off the divisor
and records \(m\) Taylor coefficients at \(a\). Since the zeros are locally
finite, its global sections are the **product**, not the direct sum, of these
finite-dimensional fibers. The claim checked here is the concrete algebraic
sequence of unrestricted functions:

\[
0\longrightarrow g\mathscr O(\mathbb C)\longrightarrow\mathscr O(\mathbb C)
\longrightarrow\prod_{g(a)=0}\mathbb C^{\operatorname{ord}_a(g)}
\longrightarrow0,\qquad f\longmapsto (f^{(k)}(a)/k!)_{a,k}.
\]

The first arrow is inclusion; the checked endpoints give kernel and
surjectivity of the jet map. They do not package an isomorphism of topological
vector spaces, formalize Cartan's theorem, identify a theta range, or
assert strip-Schwartz interpolation. The preceding Mellin display has a
separate [kernel and obstruction audit](rational-mellin-divisor-kernel.md).

## Checked argument

`Lemmas.EntireDivisorInterpolation` exports `Masullo.entireDivisorJet`,
`Masullo.entireDivisorJet_eq_zero_iff`, and `Masullo.entireDivisorJet_surjective`.
The second endpoint uses the accepted `Masullo.entire_mul_iff_vanishing_jets`
from `Lemmas.EntireDivisorDivision`: Multiplying or dividing by the nonzero
factorial preserves the vanishing condition. The third endpoint uses an
explicit local-uniform construction, not sheaf cohomology:

1. At a zero \(a\), the identity theorem makes its order finite. Extract
   \(g(z)=(z-a)^m h(z)\) with \(h\) entire and \(h(a)\ne0\) via
   `Masullo.entire_extract_finset_factors`. For the desired polynomial
   \(Q(z)=\sum_{k<m}J(a,k)(z-a)^k\), take the degree-\(<m\) Taylor
   truncation \(T\) of \(Q/h\) at \(a\). Put \(B=hT\). The Taylor remainder
   makes \(Q-B\) vanish to order at least \(m\); away from \(a\), \(B=gR\)
   with \(R=T/(z-a)^m\) holomorphic there. Thus at every other zero the
   entire block has zero jets below the multiplicity.
2. For \(a\ne0\), approximate \(R\) by a Taylor polynomial \(P\) at the
   origin, using holomorphy on the disk of radius \(3|a|/4\). Uniform
   approximation on the smaller disk of radius \(2|a|/3\) and boundedness
   of \(g\) make \(F_a=B-gP\) arbitrarily small on \(|z|\le |a|/2\).
   Subtracting \(gP\) preserves **every** prescribed jet, by the kernel
   criterion. The block at \(a=0\) needs no bound.
3. Each compact contains finitely many zeros. A countable exhaustion
   gives an injection \(e\) from the zero subtype into \(\mathbb N\).
   Use \(2^{-e(a)}\) as the bound in step 2. On each compact this summable
   bound holds for all but finitely many blocks. Consequently the net of
   finite sums converges locally uniformly to an entire function. For
   each fixed \(a,k\), the \(k\)th derivatives of those sums converge at
   \(a\) to the derivative of the limit. The derivatives are already
   constant once the finite set includes \(a\): Only the \(a\) block has
   nonzero contributions there. This proves the Taylor coefficient
   equality for every \(k\) below the multiplicity. The same proof uses
   finite sums for finitely many zeros and the empty sum for no zeros.

There is no added axiom, native computation, or proof admission. The joint
axiom checks below each report `[propext, Classical.choice, Quot.sound]`.

The ordinary-import client applies surjectivity to an arbitrary full array,
checks the factorial convention on a repeated zero, and applies the kernel
equivalence to obtain an entire quotient.

```lean
import Lemmas.EntireDivisorDivision
import Lemmas.EntireDivisorInterpolation

open Masullo Set

#check @entire_mul_iff_vanishing_jets
#print axioms entire_mul_iff_vanishing_jets
#check @entireDivisorJet
#print axioms entireDivisorJet
#check @entireDivisorJet_eq_zero_iff
#print axioms entireDivisorJet_eq_zero_iff
#check @entireDivisorJet_surjective
#print axioms entireDivisorJet_surjective

-- Prescribe an arbitrary array and recover the unnormalized derivatives.
example {g : ℂ → ℂ} (hg : AnalyticOnNhd ℂ g univ) (hne : g ≠ 0)
    (J : ∀ a : {z : ℂ // g z = 0}, Fin (analyticOrderAt g a.val).toNat → ℂ) :
    ∃ f : ℂ → ℂ, AnalyticOnNhd ℂ f univ ∧
      ∀ a k, iteratedDeriv k.val f a.val = J a k * (k.val.factorial : ℂ) := by
  obtain ⟨f, hf⟩ := entireDivisorJet_surjective hg hne J
  refine ⟨f.val, f.property, fun a k ↦ ?_⟩
  exact (div_eq_iff (by exact_mod_cast k.val.factorial_ne_zero)).mp
    (congrFun (congrFun hf a) k)

-- At a triple zero the coefficient B of z^2 corresponds to f''(0) = 2 B.
example (A B : ℂ) : ∃ f : ℂ → ℂ, AnalyticOnNhd ℂ f univ ∧
    f 0 = A ∧ iteratedDeriv 2 f 0 = 2 * B := by
  let g := fun z : ℂ ↦ z ^ 3
  have hg : AnalyticOnNhd ℂ g univ := fun _ _ ↦ analyticAt_id.pow 3
  have hg₀ : g ≠ 0 := by
    intro h
    have h1 := congrFun h (1 : ℂ)
    norm_num [g] at h1
  have hord₀ : analyticOrderAt g 0 = (3 : ℕ∞) := by
    change analyticOrderAt ((id : ℂ → ℂ) ^ 3) 0 = _
    rw [analyticOrderAt_pow analyticAt_id, analyticOrderAt_id]
    norm_num
  have hord : (analyticOrderAt g 0).toNat = 3 := by rw [hord₀]; rfl
  let a : {z : ℂ // g z = 0} := ⟨0, by norm_num [g]⟩
  let J (b : {z : ℂ // g z = 0}) (k : Fin (analyticOrderAt g b.val).toNat) : ℂ :=
    if k.val = 0 then A else B
  obtain ⟨f, hf⟩ := entireDivisorJet_surjective hg hg₀ J
  have hv := congrFun (congrFun hf a) (⟨0, by rw [hord]; decide⟩ :
    Fin (analyticOrderAt g a.val).toNat)
  have hd := congrFun (congrFun hf a) (⟨2, by rw [hord]; decide⟩ :
    Fin (analyticOrderAt g a.val).toNat)
  change iteratedDeriv 0 f.val 0 / ((0 : ℕ).factorial : ℂ) = (if (0 : ℕ) = 0 then A else B) at hv
  change iteratedDeriv 2 f.val 0 / ((2 : ℕ).factorial : ℂ) = (if (2 : ℕ) = 0 then A else B) at hd
  norm_num [iteratedDeriv_zero, Nat.factorial] at hv hd
  refine ⟨f.val, f.property, hv, ?_⟩
  rw [mul_comm]
  exact (div_eq_iff (by norm_num : (2 : ℂ) ≠ 0)).mp hd

-- Obtain the entire quotient, with its value determined by division off the divisor.
example {f g : ℂ → ℂ} (hf : AnalyticOnNhd ℂ f univ) (hg : AnalyticOnNhd ℂ g univ)
    (hne : g ≠ 0) (hj : ∀ a k, entireDivisorJet (g := g) f a k = 0) :
    ∃ q : ℂ → ℂ, AnalyticOnNhd ℂ q univ ∧ ∀ z, g z ≠ 0 → q z = f z / g z := by
  have hzero : entireDivisorJet (g := g) f = 0 := funext fun a ↦ funext (hj a)
  obtain ⟨q, hq, hm⟩ := (entireDivisorJet_eq_zero_iff hf hg hne).mp hzero
  refine ⟨q, hq, fun z hz ↦ (eq_div_iff hz).mpr ?_⟩
  simpa [Pi.mul_apply, mul_comm] using (congrFun hm z).symm
```
