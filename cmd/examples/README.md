# Archived Gödel programs

These are source examples, not supported launch targets. Their prompts, commands,
and history lookups retain the `cmd/<name>` paths they used when active. Use the
original revision to reproduce an old run; do not point a new run at its ledger.

| Example | What to look at |
| --- | --- |
| [audit](audit/) | Review accepted changes and journal the findings. |
| [blitz](blitz/) | Organize a bounded research effort across several roles. |
| [companion](companion/) | Select neglected manuscript claims for independent investigation. |
| [conjecture](conjecture/) | Turn research proposals into cards with supporting evidence. |
| [formalize](formalize/) | Coordinate proof work from Walk's ledger. |
| [godel](godel/) | Separate the manuscript work graph from its improvement graph. |
| [walk](walk/) | Traverse manuscript passages and track independent reviews. |

The active programs are [Alice](../alice/), [Bob](../bob/), [Eve](../eve/),
and [Mallory](../mallory/). The [ff graph helper](../ff/) remains runnable at
`go run ./cmd/ff graph` from the repository root.
